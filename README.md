# Macro Tracker 

Этот репозиторий создан в рамках курсового проекта по созданию веб-сервиса для контроля питания и подсчета КБЖУ.

## Текущий этап: Сбор и подготовка данных
На данном этапе я собрала базу данных продуктов и математическую базу для расчетов, а также данные для анализа актуальности проекта.

## Что внутри
- "data/food_data.csv" — база данных популярных продуктов с их КБЖУ.
- "formulas.md" — файл с формулами (ИМТ, базовый метаболизм, расчет КБЖУ), которые будут использоваться в приложении.
- "data/competitors.csv"(Сравнение конкурентов) — проведен ручной анализ 8 популярных приложений для контроля питания, который
показывает, что 90% приложений заточены в основном под похудение и навязывают диеты. Только 1 приложение (Cronometer) частично поддерживает набор веса. Это доказывает свободную нишу на рынке.
- "data/user_reviews.csv" (Реальные отзывы пользователей) - проведен ручной сбор отзывов из магазинов приложений Google Play и App Store, который
показывает, что люди с целью "набрать вес" чувствуют дискомфорт, вину и не могут найти подходящий инструмент из-за навязывания ПП. Это подтверждает актуальность нашего проекта.
